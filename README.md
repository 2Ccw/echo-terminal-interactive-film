# 回声终端

一部可在浏览器完整通关的原创近未来悬疑互动影游。玩家进入停机七年的记忆局，在“相信谁、公开什么、由谁承担代价”之间做出不可逆选择。

## 一步启动

需要 Node.js 18+：

```bash
npm install
npm start
```

打开 <http://localhost:4173>。不配置任何密钥也能从序章玩到全部结局。

测试：

```bash
npm test
```

## 内容与设计

- 12 个剧情场景，3 组关键分歧，5 个独立结局
- 决策影响后续场景、角色关系、信息公开范围与最终代价
- 本地自动存档；移动端和桌面端自适应
- Canvas 实时生成雨幕、终端扫描网格、警报与晨曦等镜头氛围
- Web Audio 实时合成选择反馈音，不依赖外部音频素材

故事围绕“遗忘是否也需要同意”展开。剧情没有简单善恶值：公开真相会侵犯隐私，保留一个人的意识会继续囚禁其他人的记忆，牺牲也不自动等于正确。

## AIGC 使用说明

### 开发阶段

故事世界观、分支图、场景文本、提示词、代码和测试由 OpenAI Codex 辅助生成，再按完整性、分支有效性和工程可运行性进行整理。剧情及全部素材为本项目原创，没有使用影视、游戏 IP 或第三方图片/音频。

### 产品运行阶段

在两个身份转折点，应用会把玩家代号、已发生剧情和真实选择发送到服务端。模型不是自由聊天，而是受约束的叙事环节：

1. 仅生成一句第二人称“记忆回响”；
2. 不得增加剧情事实、剧透或评价玩家；
3. 强制 JSON 输出并校验长度；
4. 9 秒超时，错误、超时、无密钥均切换确定性离线文案。

如需开启实时生成，将 `.env.example` 复制为 `.env`，填写 OpenAI-compatible 配置：

```env
OPENAI_API_KEY=your_key
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
```

密钥只保存在服务端，不会下发浏览器。即使模型不可用，按钮、分支和结局都不会卡死。

## 技术栈

- 原生 HTML / CSS / JavaScript
- Canvas 2D、Web Audio、LocalStorage
- Node.js + Express（静态托管与模型代理）
- Node 内置测试运行器

## 项目结构

```text
public/story.js       剧情图谱与全部结局
public/app.js         状态机、存档、AIGC 调用、Canvas 与声音
public/styles.css     响应式视觉系统
server.js             静态服务、模型代理、超时与离线兜底
test/story.test.js    剧情节点、可达性与结局完整性测试
```

## 已知问题

- 游玩时长取决于阅读速度，快速阅读约 12–15 分钟，沉浸阅读约 20–30 分钟。
- 浏览器自动播放策略要求玩家先点击声音按钮，声音才会启用。
- 当前存档只保留一条时间线；重新开始会覆盖旧存档。

## AI 图像说明

本项目没有把 AI 生成图片冒充为手工素材。制作环境的内置图像生成工具不可用，因此最终视觉采用程序化 Canvas；背景不是网络下载图片。这样也保证项目离线可运行、无版权和资源加载风险。
